# Poms

This repository now contains two small games:

1. **Poms** - a simple console game in C++. Four teams try to move all their apples into opponents' zones. The first team that empties its own zone wins.
2. **Tic Tac Toe** - the original Python implementation for two players.

## Running the C++ Poms Game

Compile and run with `g++`:

```bash
# compile
g++ -std=c++17 -Wall -Wextra -pedantic poms.cpp -o poms
# run
./poms
```

## Running the Tic Tac Toe Game

Execute the Python game with:

```bash
python3 game.py
```

Both games run in the terminal and require manual input from the players.
